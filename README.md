# APK Kasir Warkop48
WebView yang langsung membuka `<situs>/#/admin`, dengan jembatan `AndroidApp` untuk cetak Bluetooth (SPP), unggah file, dan simpan unduhan.
Build: GitHub > Actions > Build APK Kasir > Run workflow > isi alamat situs. Unduh `app-debug.apk` dari Artifacts, pasang di tablet (izinkan sumber tidak dikenal).
Android 10 ke atas. Ikon masih bawaan Android.
